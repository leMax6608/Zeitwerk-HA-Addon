# Zeitwerk

Private Arbeitszeiterfassung mit Pausenzähler, Kalender und Zeitkonto für Home Assistant.

Installationsanleitung und Funktionsübersicht stehen in der `README.md` im Hauptverzeichnis des Repositories. Persönliche Zeiten und Einstellungen werden nicht mit diesem Quellcode ausgeliefert, sondern lokal im persistenten App-Datenordner gespeichert.
