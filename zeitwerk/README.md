# Zeitwerk – Arbeitszeit

Erfasse Arbeit und Pausen, plane freie Tage und behalte dein Zeitkonto im Blick – privat auf deinem Home-Assistant-Gerät.

- [Schnellstart und Installation](../README.md)
- [Bedienung und weitere Details](DOCS.md)
- [Änderungsverlauf](CHANGELOG.md)

Persönliche Zeiten und Einstellungen gehören nicht zum Quellcode. Sie bleiben im persistenten App-Datenordner und können als JSON gesichert werden.
